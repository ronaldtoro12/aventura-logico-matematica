# Aventura Lógico-Matemática

Juego educativo interactivo para niños, con seis mundos, retos ilustrados en 2D, narración en español y progreso guardado en el navegador.

## Jugar

https://zenitha.github.io/aventura-logico-matematica/

## Publicación

El sitio se publica en GitHub Pages automáticamente al subir cambios a la rama `main`. El flujo está en `.github/workflows/pages.yml`.
